# Gerador-de-Senhas
## Funcionalidades:
- Geração Istantânea de senhas;
- Escolha do número de caracteres (4 a 32);
- Inclusão de: letra maiuscúla, letra minuscúla simbolo e núimeros;
- Barra indicativa da força da senha;
- Interface responsiva;
- Atualização automatica da senha sempre que uma configuração e alterada.

 ## Responsividade
 - O projeto foi desenvolvido para funcionar em diferentes tamahos de tela, oferecendo uma boa experiência tanto em computadores quanto em despositivos moveis.

  ## Objetivo do projeto
  - Esse projeto foi desenvolvido com fins educasionais para praticar conceitos de desenvolvimento front-end, incluindo:
  - Eventos em JavaScript;
  - Organização de código;
  - Geração aleatória de caracteres;
  - Resposividade com CSS;
